# 数据处理与隐私边界

## 本地保存

- 实例配置、应用 Profile、浏览器 Profile、运行日志、Manifest 和 SQLite 元数据保存在本机；
- `config.json` 仅作为兼容导出，SQLite 是运行时元数据源；
- 诊断接口只输出脱敏相对路径、状态、PID 摘要、出口配置状态和错误边界。

## 明确禁止进入诊断包/日志

- Cookie、Session、Token、Bearer、授权码、PKCE、完整授权 URL；
- 代理账号密码、私钥、验证码、支付信息；
- 用户文档正文、聊天内容和实例共享素材内容。

## 用户控制

- 实例历史默认持久化；清理、删除、重置必须是显式动作；
- 备份恢复不覆盖已存在实例；
- 用户可删除本地 data 和实例目录，但应先备份；
- 网络出口由用户提供并承担合规责任，工具不抓取免费代理。

## 外部服务边界

当前项目不会把本地启动、授权浏览器打开或 UI 文案解释为目标平台成功。目标平台的登录、签到、设备识别和业务回执必须由用户在真实环境中确认。
