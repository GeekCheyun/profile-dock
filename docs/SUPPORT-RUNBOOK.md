# 试点支持与诊断运行手册

## 首次收集

1. 记录产品版本、Windows 版本、Electron 版本、目标应用版本和是否使用 Edge/Chrome。
2. 让用户复现一次问题，记录实例编号、时间和界面错误，不要求用户发送 Cookie、Token、授权码或完整授权链接。
3. 导出对应实例的脱敏诊断报告：`GET /api/instances/:box/diagnostics`。
4. 如需迁移，先使用 `server/backup.ts` 生成备份，再进行恢复；恢复过程禁止覆盖已存在实例。

## 分流规则

| 现象 | 先查 | 处理边界 |
| --- | --- | --- |
| 窗口打不开 | 端口、构建产物、普通权限、Electron 日志 | 不要求管理员运行 |
| 实例被误判运行 | Manifest、主 PID、Job Object | 不终止宿主或越界目录 |
| 授权失败 | 当前链接、loopback 监听 PID、实例浏览器 Profile | 不重放旧链接，不收集 PKCE |
| 出口失败 | 可信代理预检、证书校验、失败闭锁状态 | 不自动切换免费代理或直连 |
| 登录态丢失 | 实例目录、备份清单、迁移记录 | 不删除用户 data |

## 升级支持

- 先保存版本、诊断报告和实例备份；
- 升级只替换程序文件，不覆盖 `data/`、实例目录和浏览器 Profile；
- 升级失败先回滚程序，再恢复备份；不得直接清空实例目录；
- 需要外部平台成功回执时，明确标记为“待用户在目标应用验证”。
