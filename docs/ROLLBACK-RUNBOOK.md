# 回滚运行手册

## 原则

回滚只替换程序文件，不删除实例目录、浏览器 Profile、SQLite 数据或用户共享素材。

## 顺序

1. 停止目标版本管理器和其 Job Object 管理的实例；
2. 保存当前版本、日志、Manifest、诊断报告和 SQLite 备份；
3. 关闭管理器进程，确认 17890 端口释放；
4. 恢复上一版本程序目录或便携候选目录；
5. 启动旧版本，先验证档案读取和实例目录，再验证目标应用；
6. 迁移失败时保留原目录，禁止自动覆盖或删除；
7. 将失败版本、错误码和恢复结果写入发布记录。

## 不能自动决定的情况

- 数据库格式需要不可逆迁移；
- 目标应用版本改变了登录或授权协议；
- 代码签名证书吊销或更新服务不可用；
- 用户要求删除历史数据。

这些情况必须暂停在恢复安全边界，不自动做不可逆处理。
